# Go Yokoyama (横山 豪)

慶應義塾大学 SFC 在籍。仮説検証のスピードを最優先に、身近な課題や対話体験を Web / モバイル / AI アプリケーションとして形にしています。
TypeScript (React / Next.js / React Native・Expo) と Python (FastAPI / データ処理 / BLE・OSC デバイス連携) を軸に、マルチプラットフォーム・フルスタック開発に取り組んでいます。
